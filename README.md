
# ENVISAT and ERS (A)SAR instrument GPU focusser

The `asar-focus` processor processes synthetic-aperture radar (SAR) Level-0 data from the ERS-1, ERS-2, and Envisat/ASAR missions into Level-1 products.

This processer is being developed in the frame of [IDEAS-QA4EO](https://qa4eo.org/) (ESA contract 4000128960/19/I-NS lead by Telespazio VEGA UK), software development by CGI Estonia AS and Cloudflight Austria GmbH.

The generated products are using the Envisat format, similar to the original [Envisat/ASAR](https://earth.esa.int/eogateway/documents/20142/37627/PO-RS-507316_4_C_Envisat_Product_Spec_Vol8.pdf/) and [ERS](https://earth.esa.int/eogateway/documents/20142/37627/ERS-products-specification-with-Envisat-format.pdf) products.
